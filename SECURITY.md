# Security Policy

## Sensitive Data

Do not open public issues or pull requests containing real customer PII, health information, financial data, policy numbers, claim numbers, secrets, tokens, or credentials.

## Reporting

If you discover a vulnerability or accidental sensitive-data exposure, report it privately to the repository owner. Do not include real customer data in the report unless explicitly requested through a secure channel.

## Production Integrations

Production CRM, carrier, policy, claims, or compliance integrations must use least-privilege credentials, audit logging, retention rules, and agency compliance approval.

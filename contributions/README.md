# Contribution Workflow

Public institution packs must be maintained through standardized contributions, not ad-hoc local wiki uploads.

## Preferred Flow

1. Create a public source record or contribution bundle.
2. Ensure it contains no customer data and no non-public/confidential material.
3. Generate proposed pages that follow the institution pack `SCHEMA.md`.
4. Run validators.
5. Submit a PR for human review.

## Contribution Types

- **Source-first contribution:** metadata about a public source, with optional short summary.
- **Curated page contribution:** proposed wiki pages that cite source records and follow schema.
- **Bundle contribution:** source records + proposed pages + provenance in one reviewable folder.

## Do Not Submit

- customer data;
- non-public insurer materials;
- full copyrighted documents unless redistribution is permitted;
- unsupported product claims;
- final recommendations or sales pressure language.
